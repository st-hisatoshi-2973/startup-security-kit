# 外部通信セキュリティ

このディレクトリでは、外部サービスやAI APIなどへの通信を、セキュリティ設計としてどのように把握・制御するかを扱います。

---

# このディレクトリで扱う内容

このディレクトリでは、主に次のような観点を扱います。

* 外部通信をどのように把握するか
* どの通信先を許可するか
* 不要な外部通信をどう防ぐか
* 動的な外部通信をどう扱うか
* 外部通信をどのように可視化・追跡するか

重要なのは、

**「通信できること」を前提にするのではなく、「必要な通信だけを許可する」**

という考え方です。

---

# AI Gatewayとの関係

AI利用では、外部のモデルAPIや外部ツールとの通信が発生します。

AI Gatewayは、単に通信を禁止するための仕組みではなく、

* どこへ通信するか
* 何を送信するか
* どの利用を記録するか

を制御・可視化するための設計上の制御ポイントになります。

このディレクトリでは、その中でも特に

**「どこへ通信してよいか」**

という通信先制御の観点を扱います。

---

# 機密情報検出との関係

外部通信では、 **「どこへ通信するか」**だけでなく、

**「何を送るか」**

も重要になります。

そのため、機密情報検出とも密接に関係します。
