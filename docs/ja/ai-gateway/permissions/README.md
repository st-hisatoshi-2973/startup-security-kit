# AI利用の権限設計

このディレクトリでは、AI利用における権限設計をどのように考えるかを扱います。

従来システムでは、

* ユーザー
* API
* サービス

に対するアクセス制御が中心でした。

しかしAI利用では、

**AI自体が実行主体になる**

ケースが増えています。

例えば：

* ファイルを読む
* コマンドを実行する
* 外部サービスへ通信する
* GitHubを操作する
* クラウド環境へアクセスする
* DBへ接続する

などです。

そのため、

**「AIに何を許可するか」**

自体が重要なセキュリティ設計になります。

---

# このディレクトリで扱う内容

このディレクトリでは、主に次のような観点を扱います。

* 何にアクセスできるか
* 何を実行できるか
* どの操作に承認を必要とするか
* どのように追跡・監査するか

重要なのは、

**「AIに自由な権限を与える」のではなく、「必要な権限だけを許可する」**

という考え方です。

---

# AI Gatewayとの関係

AI Gatewayは、AI利用における制御ポイントとして機能します。

このディレクトリでは、特に

**「AIに何を許可するか」**

という権限設計の観点を扱います。

---

# 外部通信制御との関係

AI利用では、外部サービスやAI APIへの通信が発生します。

そのため、

* どこへ通信できるか
* どの外部ツールを利用できるか

も権限設計の一部になります。

---

# 機密情報検出との関係

AI利用では、認証情報や機密情報へAIがアクセスできる場合があります。

そのため、

* どの情報へアクセスできるか
* どの情報をAIへ送信してよいか

も権限設計の一部になります。
